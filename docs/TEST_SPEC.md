# River Club — 포커 대회용 웹 테스트 명세서 (v1.0 초안)

> 대상: `apps/web` (서버리스 호스트 권위형 엔진 `LocalPokerTable` + MQTT 동기화 + React UI)
> 승인 후 `docs/TEST_SPEC.md`로 복사하고, **[AUTO]** 항목은 Vitest, **[E2E]** 항목은 Playwright, **[MAN]** 항목은 수동 체크리스트로 관리합니다.

**우선순위**: P0 = 대회 진행 불가/공정성 훼손, P1 = 주요 기능 오류, P2 = 경미/UX
**자동화 표기**: AUTO(단위/통합) · E2E(브라우저 다중 세션) · MAN(수동)

## 13. 알려진 위험 (현재 코드 기준)

> [!CAUTION]
> **R1 (SEC-001)** `toJSON()`이 `players[].cards`와 `deck` 전체를 MQTT 공개 토픽(retained)에 게시합니다. 토픽명을 아는 누구나 **모든 홀카드와 다음 카드**를 볼 수 있어 대회 공정성이 성립하지 않습니다.
> **R2 (SEC-003)** 닉네임이 같으면 기존 좌석에 병합(`join`)되어 **타인 좌석/스택 탈취**가 가능합니다.
> **R3** 호스트 브라우저가 단일 권위(Single Point of Failure)이며 호스트는 모든 카드를 볼 수 있습니다.
